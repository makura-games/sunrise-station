# ENV для переводов

Скрипты этой папки не читают собственные переменные окружения и не загружают `.env`-файлы.

| Настройка | Где нужна | Что означает |
| --- | --- | --- |
| Собственные ENV | Не требуются | Пути и параметры обработки задаются в самих инструментах. |
| `PAT` | Секрет GitHub в сценарии **Update Locale** | Ключ GitHub для доступа к репозиторию. Его читает шаг получения кода, а не скрипты переводов. Для сохранения переводов ключу нужны права записи. |

[Как добавить секрет](../how-to-env.md). Добавление `PAT` само по себе не исправляет сценарий: сейчас он ссылается на старые пути `Tools/_sunrise/keyfinder.py` и `Tools/_sunrise/yamlextractor.py`, а файлы лежат в этой папке. Также получение кода настроено без сохранения ключа для последующей отправки изменений.
