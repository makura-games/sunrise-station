# ENV для проверки текстов

Переменные окружения и секреты не требуются. `validate_yml.py` получает настройки как параметры запуска.

| Параметр | Обязателен | Что передать |
| --- | --- | --- |
| `localization_dir` | Да | Папку переводов, обычно `Resources/Locale/`. |
| `yml_dir` | Да | Папку описаний игровых объектов, обычно `Resources/Prototypes/`. |
| `--ignore` | Да | Файл исключений: `Tools/_sunrise/Schemas/ignore_list.yml`. |

Сценарий **Locale Validator** передаёт эти пути сам. Создавать одноимённые переменные в настройках GitHub не нужно.
