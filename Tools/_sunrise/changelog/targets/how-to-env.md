# Настройка целей Discord

Эта папка хранит обычные YAML-настройки, не `.env`-файлы. Для каждой цели создайте отдельный файл по образцу `example.yml` и заполните два поля.

| Поле файла | Что означает | Пример |
| --- | --- | --- |
| `changelog_file` | Путь к списку изменений от корня репозитория. Файл должен существовать, в том числе в публикуемом коммите. | `Resources/Changelog/ChangelogSunrise.yml` |
| `webhook_secret` | Имя секрета GitHub с адресом нужного канала Discord. Здесь записывается имя, а не сам адрес. | `CHANGELOG_DISCORD_WEBHOOK_SUNRISE` |

Создайте секрет с точно таким именем в настройках репозитория и сохраните в нём полный адрес отправки сообщений. [Как добавить секрет](../../how-to-env.md).

| Передаваемая ENV | Как получается |
| --- | --- |
| `CHANGELOG_TARGET_ID` | Имя выбранного файла без `.yml`: для `sunrise.yml` это `sunrise`. |
| `CHANGELOG_FILE` | Значение поля `changelog_file`. |
| `DISCORD_WEBHOOK_URL` | Значение секрета, названного в `webhook_secret`. |
| `GITHUB_OUTPUT` | Служебный файл GitHub для передачи выбранных настроек следующему шагу. |

Пустые и полностью закомментированные файлы пропускаются. [Остальные ENV отправки](../how-to-env.md) задаёт сценарий автоматически.
