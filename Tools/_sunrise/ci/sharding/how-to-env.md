# ENV для распределения тестов

Создавать переменные или секреты в GitHub для этой папки не нужно. Число групп, пути к файлам и номера измерений передаются параметрами команды.

| ENV | Кто задаёт | Для чего нужна |
| --- | --- | --- |
| `PATH` | Операционная система; скрипт подготовки дополняет его | Помогает найти установленный .NET. `prepare_test_shards.py` добавляет папку `.dotnet` из домашнего каталога пользователя. |
| `DOTNET_CLI_UI_LANGUAGE` | `prepare_test_shards.py` | Сам выставляет `en-US`, чтобы список тестов был на ожидаемом английском языке. |

Файл `integration_test_timings.json` содержит измеренные длительности тестов; это не файл ENV. Переменные `SHARD`, `PROFILE_RUNS` и другие параметры сценария описаны [в родительском разделе](../how-to-env.md).
