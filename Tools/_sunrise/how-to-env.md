# Переменные окружения: общие правила

Переменная окружения, или ENV, — именованная настройка для запуска программы. Эти скрипты не загружают `.env`-файлы автоматически.

## Где задавать значения

Откройте репозиторий на GitHub: **Settings → Secrets and variables → Actions** («Настройки → Секреты и переменные → Автоматизация»).

| Обозначение в справочниках | Что делать |
| --- | --- |
| Переменная GitHub | Вкладка **Variables** → **New repository variable**. Укажите имя и значение. |
| Секрет GitHub | Вкладка **Secrets** → **New repository secret**. Здесь хранятся ключи доступа и закрытые адреса отправки сообщений. |
| Поле запуска | Откройте **Actions**, выберите нужный сценарий и нажмите **Run workflow**. Заполните форму запуска. |
| Автоматически | Ничего не создавайте в настройках: значение передаёт GitHub или сам сценарий. |
| Локально | Задайте значение в том же терминале, где запускаете скрипт. |

Официальная справка: [переменные GitHub](https://docs.github.com/en/actions/how-tos/write-workflows/choose-what-workflows-do/use-variables), [секреты GitHub](https://docs.github.com/en/actions/how-tos/write-workflows/choose-what-workflows-do/use-secrets). Секреты не записывайте в файлы репозитория.

Пример для PowerShell: `$env:CHANGELOG_FILE = 'Resources/Changelog/ChangelogSunrise.yml'`. Для Bash: `export CHANGELOG_FILE='Resources/Changelog/ChangelogSunrise.yml'`. Значение действует в текущем терминале и запущенных из него программах.

## Скрипты в этой папке

| Имя | Где задаётся | Назначение и значение |
| --- | --- | --- |
| `GEMINI_API_KEY` | Секрет GitHub; обязателен для ИИ-ревью | Ключ доступа к Gemini. Без него проверка не запускается. |
| `GEMINI_MODEL` | Секрет GitHub в текущем сценарии ИИ-ревью | Имя доступной модели Gemini. Для локального запуска, если переменная отсутствует, код использует `models/gemini-1.5-pro`; доступность модели нужно проверить отдельно. Не оставляйте передаваемое значение пустым. |
| `MAX_OUTPUT_TOKENS` | Локально; необязательно | Максимальная длина ответа ИИ в токенах — частях слов. По умолчанию `1500`. Текущий сценарий GitHub это значение отдельно не передаёт. |
| `TEMPERATURE` | Локально; необязательно | Степень разнообразия ответа ИИ. По умолчанию `0.2`; дробная часть отделяется точкой. |
| `DISCORD_WEBHOOK_URL` | Автоматически при публикации; локально — вручную | Закрытый адрес для отправки уведомления об обновлении в канал Discord. Берётся из секрета `ANNOUNCE_UPDATE_DISCORD_WEBHOOK`. |
| `DISCORD_ROLE_ID` | Автоматически при публикации; локально — вручную | Числовой ID роли для упоминания. Берётся из секрета `ANNOUNCE_UPDATE_DISCORD_ROLE_ID`. Без адреса или роли уведомление пропускается. |
| `BUILD_PATH` | Автоматически; необязательно локально | Путь к архиву клиента для показа его размера. При публикации — `./release/SS14.Client.zip`. |

Остальные скрипты корневой папки не требуют собственных ENV. Настройки разделов: [публикация](publishing/how-to-env.md), [чейнджлог](changelog/how-to-env.md), [тесты](ci/how-to-env.md), [переводы](localization/how-to-env.md), [проверка текстов](Schemas/how-to-env.md).
